# Birthday Countdown

Small vanilla JS countdown to the next birthday. No build step, no dependencies.

- Counts down to the **next** occurrence of any birthday (repeats every year)
- Set name and date in the form, saved in `localStorage`
- Or share a link: `index.html?name=Chris&date=1990-06-04`
- Mobile friendly, light/dark mode, respects reduced motion

## Run

Open `index.html` in a browser.
